Redis 数据结构图解

吉祥物「小方」会在每种类型旁陪你观看演示。点击下方标签切换类型，可随时点「再播一遍」重看动画。 内容为入门向示意，与真实内存布局无关。

String — 键值一体

SET greeting "你好 Redis" · GET greeting · INCR page_view

greeting 你好 Redis
INCR → 1

List — 双向队列

LPUSH jobs A → LPUSH jobs B → LPUSH jobs C · RPOP jobs 从右侧弹出

C
B
A

左侧不断 LPUSH「插队」，右侧 RPOP「领任务」。

RPOP!

Hash — 一行对象多字段

HSET user:1 name 小方 · HSET user:1 level 3 · HGETALL user:1

字段值
name 小方
level 3

Set — 不重复成员

SADD tags rust · SADD tags web · 再次 SADD tags rust → 返回 0，集合不变

rust
web

再次 SADD rust：已是成员，拒绝重复～

Sorted Set — 带分数的排行榜

ZADD leaderboard 100 alice · ZADD leaderboard 250 bob · ZADD leaderboard 180 carol · ZRANGE 按分数排序

alice 100
carol 180
bob 250

Stream — 追加型日志

XADD events * action login · XADD events * action click · XREAD 消费新消息

login click

消息像小船顺流而下，消费者按偏移读取。
